# Exact-white rigid vertex colors

Hypothesis: immutable rigid primitives whose effective CPU colors are exactly finite [1,1,1,1] need no 16-byte vertex color fetch. Removing the color interpolator is a separately tested sub-hypothesis. This reduces initial vertex upload and known retained rigid-buffer capacity; steady-state timing must be measured separately.

Proof scans every vertex in the primitive range once at immutable GPU asset preparation, including unindexed vertices. Empty/nonfinite/near-white/nonidentity alpha inputs are not eligible. CPU ModelAsset colors and topology are untouched. Morph and skin draws retain their original full layout; a primitive referenced by both rigid and skin nodes gets independent rigid and skin GPU buffers. Existing material-used UV/tangent packing stays in effect.

Geometry owns the omission fact and actual stride. Draw copies it only on the rigid path. Pipeline Variant and ShaderKey independently include the fact. SharedAsset ownership, draw identity and per-asset batch classes already prevent cross-geometry mixing; no camera quantization or new plan cache is introduced. All auxiliary passes use the same explicit variant bit. Shader specialization removes Input color after skin/instance injection and writes constant white in the vertex shader. The original Output varying and fragment multiplication are retained: omitting them produced a repeatable one-pixel/right-eye WebGPU XR difference, max2/255, while both same-layout reload controls were exactly repeatable. Zero tolerance was preserved. This part of the hypothesis is rejected; the finite-precision interpolator remains necessary for strict baseline pixels in this tested variant. Material base/alpha, all textures, alpha testing, normals and other factors are unchanged.

The reference control setGltfWhiteColorOmissionEnabled rejects changes while immutable GPU assets remain live. A cleared/reinitialized renderer may choose original layout for the same loader inputs; existing prepared data are invalidated on a policy change. This is an independent original-layout reference, not a second copy of the optimized eligibility algorithm. Compact debug stats expose aggregate live Buffer.size(), compiled shader/pipeline counts, cumulative rigid vertex upload and omitted bytes. The on-demand gltfVertexLayouts() query exposes primitive stride and actual Buffer.size() outside timing windows. An exploratory ordinary-scene series with detailed layouts inside periodically polled debugStats is retained and excluded from final clean pairs; that serialization was unnecessary measurement overhead. Requested GPU bytes exclude driver padding/metadata, textures, indices and deforming buffers.

Acceptance: exact pixels against the original-layout control on both backends; actual stride and Buffer.size assertions; mixed colored/colorless primitives, alpha modes, normal mapping, translation/full mirrored/nonuniform instances, auxiliary passes, CPU fallback and clear/dispose. Existing simulated XR and real cutting tests remain independent regressions. Physical Quest is not available in this task.
