# Lossless portable index storage

Hypothesis: use16-bit GPU indices for normalized primitive sequences whose actual maximum is at most65534. This reduces immutable index payload/upload and retained buffer capacity. Any steady-state time benefit is a separate measured hypothesis. CPU ModelAsset indices, collision/cutting geometry, vertex ordering and primitive order remain unchanged.

Normalize line loops into ordered line pairs and triangle fans into the original ordered triangle list first. All other modes retain their index sequence. Missing indices generate the original0..vertex_count sequence. Select storage from the actual resulting values, never the number of entries or vertices. Checked u16 conversion follows the range proof. No value rounding/remapping/overflow.

[WebGL2 section5.17](https://registry.khronos.org/webgl/specs/latest/2.0/#5.17) always enables fixed-index restart, including non-strip draws.65535 must remain an ordinary Uint32 index on the portable engine path. This is valid when the glTF source accessor itself uses Uint32. [wgpu30.0.1 PrimitiveState](https://docs.rs/wgpu/30.0.1/wgpu/struct.PrimitiveState.html#structfield.strip_index_format) requires an indexed strip's format in the pipeline; include it in Variant independently of shader/layout variants. The glTF source format is not preserved blindly.

Geometry owns format, logical count and maximum; Draw and PreparedDraw copy format explicitly. draw_prepared binds the matching format for every pass and eye, including skin/morph fallback. Non-strip pipelines do not multiply unnecessarily by index format. Shared immutable geometry and existing resource identities/class membership preserve cache validity. The original-U32 reference control rejects changes while shared GPU assets remain live, invalidates prepared plans before a policy change, and does not mutate existing buffers.

DeviceExt::create_buffer_init in the pinned vendored wgpu rounds allocation size to4B and copies only payload bytes. A3-index Uint16 triangle is6B payload/8B buffer but draw_indexed uses count3. Never draw padding. Compact aggregate stats expose cumulative payload upload/requested creation bytes and current live format counts/payload/padding/Buffer.size. Detailed layouts are queried on demand outside clean timing. Requested size is not physical driver VRAM.

Acceptance: native independent expected topology sequences and boundary tests; actual real-buffer format/count/size assertions; exact pixels against original Uint32, including all modes,65534/65535/65536, many small-valued entries, sparse high entries, nonindexed, affine mirrored instances, auxiliary passes, shared source removal and clear/dispose. Simulated real-eye target reads compare original Uint32 separately. Existing real-cut/lifecycle regressions remain required. No physical Quest claim.
