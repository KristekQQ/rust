# Historical renderer evidence (B2–B8)

Historical reports only; none of these measurements was rerun for B9. Results are independent experiments and must not be summed as additive gains.

| Batch / exact comparison | Observed result; workload, backend, metric and protocol | Limitation and evidence pointers |
|---|---|---|
| B2: frozen pre-cache instrumented baseline vs candidate release. | Rome + 2,048 static drones, 1280×720, WebGPU/WebGL; 3 AB/BA/AB pairs, 8s warmup/25s sample. Repeated opaque-plan preparation vanished on warm hits; callback wall and cadence improved in this workload. | Static scene only; GPU timing off, foreign GPU load present; no Quest/Three comparison. Report [B2 report](../batch-2/REPORT.md). |
| B3: completed B2 release vs fine motion invalidation candidate. | Moving-camera/one-root cases had lower callback wall time; three paired runs/backend, 1280×720, 8s/25s, WebGPU and WebGL. One-root rows reused 240/240, while a 540,688-byte union upload remained. | Mixed/static controls approximately neutral; fully moving 1024 WebGPU strict pixels 40/42 exact, 2 FAIL, unresolved. Report [B3 report](../batch-3/REPORT.md). |
| B4: baseline vs bounded instance-resource reuse candidate. | Rome/Neon, WebGPU/WebGL, 1280×720, 3 AB/BA/AB pairs for dynamic cases, 8s/25s. In-budget repeated workloads created zero instance buffers/material bind groups after warmup. | No general FPS/tail gain; moving 1024 WebGPU strict pixels 19/20 exact, one FAIL. Report [B4 report](../batch-4/REPORT.md). |
| B5: original layout vs exact-white rigid vertex-layout candidate; separate shader experiment removed output varying/multiply. | Rome 258 eligible primitives; initial/live rigid vertex capacity 9,417,848→5,650,760 bytes; 12 paired image sets exact. Final timings: 3 pairs/config/backend, 8s/25s, WebGPU/WebGL. | No steady-state FPS gain proven. Varying-removal experiment rejected: XR right-eye cross-variant differed 1 pixel (max 2/255); original interpolation retained. B4 pixel issue remained open. Report [B5 report](../batch-5/REPORT.md). |
| B6: B5 release vs compact-index candidate (same corrected release diagnostics). | 258 shared Rome primitives; Uint32→Uint16 reduced requested index bytes 1,479,384→739,692. Paired 3-run/config/backend desktop timing, 8s/25s; all 12 image pairs exact. | Capacity/upload evidence, no steady-state speed gain; callback timing contended, GPU times unavailable. Report [B6 report](../batch-6/REPORT.md). |
| B7: unchanged-production diagnostic D vs rejected published-count C; rejected depth-order prototype separately. | D/C stress: 3 pairs/backend, WebGPU load 2048 and WebGL 1024, 8s/25s; C reduced callback work but FPS regressed in all six backend pairs. Depth prototype changed real-scene pixels (WebGL 304, max 102; WebGPU 4,533, max 101). | Both production experiments rejected and restored; no optimization accepted. Different loads prohibit cross-backend ranking. Report [B7 report](../batch-7/REPORT.md). |
| B8: canvas-transfer baseline vs opt-in shared-framebuffer prototype, same frozen release/SDK. | Simulated WebGL XR, 3 AB/BA/AB pairs/workload, 8s/25s; full stereo pixels exact. Asymmetric stress cadence/callback wall improved, while symmetric ordinary callback wall regressed. | Keep canvas-transfer default; no Quest/FBO acceptance or general speed claim. GPU intervals incomparable/inconclusive. Report [B8 report](../batch-8/REPORT.md). |
